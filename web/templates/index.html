Configuration

🔍 Scan Mode

Controls how Safe Scanarr handles new media. In Review Mode, all contact sheets are queued for manual review — flagged content is highlighted at the top for priority review. In Safe Mode, flagged content is automatically deleted and blacklisted in Sonarr/Radarr without manual review; the contact sheet is retained in the Auto-handled tab for auditing.

🔞 NSFW Detection

NudeNet runs locally (no API calls) on every contact sheet. In Review Mode, flagged items appear at the top of the queue with a warning badge for manual review. In Safe Mode, flagged items are automatically deleted and blacklisted. Threshold controls sensitivity — lower values catch more but may produce false positives.

0.5 = more sensitive, 0.7 = fewer false positives. Default: 0.6

Poller

The poller periodically checks Sonarr and Radarr for newly imported files and triggers contact sheet generation automatically — without waiting for the nightly scan. Requires Sonarr/Radarr API keys to be configured.

vcsi

vcsi generates the contact sheet thumbnails from your video files. Grid size controls how many thumbnails appear (e.g. 4x4 = 16 frames). Timeout is the maximum time allowed per file — increase this for large or slow-to-process files.

Database

Clean Database removes records for files that no longer exist on disk or are outside your current watch folders. Useful after moving or deleting media, or after changing watch folders.
