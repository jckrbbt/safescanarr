🔍 Scan Mode

Choose how Safe Scanarr responds when NSFW content is detected in a contact sheet.

🔞 NSFW Detection

Every contact sheet is automatically scanned for explicit content using NudeNet, which runs entirely on your server — no data is sent anywhere. The confidence threshold controls how certain the detection needs to be before flagging something. A lower threshold catches more content but may occasionally flag innocent material; a higher threshold is more conservative.
