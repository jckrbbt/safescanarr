# SafeScanarr v1.0.11 — "Remember me" implementation spec (planner, 2026-09-23)

FEATURE: "Remember me" checkbox on login (30 days, server-side revocable) + session invalidation fixes. Repo ~/cloud/Projects/safescanarr, on main, current 1.0.10.

## Design summary
- Rename cookie to "safescanarr_session" (fixes collision with other Flask apps on same host).
- Every session stores av = HMAC(secret_key, "v1|method|credential|session_epoch")[:32], checked on every request. Password/token change, reset+setup, or session_epoch bump kills every session.
- "Remember me" checked: session.permanent=True, session["rid"]=token_urlsafe(32), session["rexp"]=expiry epoch. DB stores only sha256(rid) in new web_sessions table. Valid only if row exists and unexpired. Logout deletes the row.
- Unchecked: exactly today's behavior (browser-session cookie, no rid), still gets av check.
- Absolute 30-day expiry from login, SESSION_REFRESH_EACH_REQUEST=False. No sliding renewal.
- Revocation: /logout (this device); new POST /api/auth/revoke-sessions (bump epoch, delete all rows except current, keep caller alive); authtool revoke-sessions; credential change; remember_me_days=0 disables.

- session_fingerprint(key: str) -> str: under _LOCK, load state; "" if not configured; credential = token_value (token mode) or password_hash (password mode); msg = f"v1|{method}|{credential}|{epoch}"; return hmac.new(key.encode(), msg.encode(), sha256).hexdigest()[:32].
